# Manual mode: launch research from uploaded reports

Use this when the user uploads a report (or asks to use one) instead of, or as well as, the Marketplace Ad Pros tools. The launch method in `SKILL.md` applies unchanged; this page covers which research steps work from files. The existing rule in `SKILL.md` still holds: if a tool isn't available, skip that step, say what it would have added, and continue.

Report layouts and column names vary by console version, marketplace and language, so never assume a fixed layout. Read what the file actually contains and tell the user what you found.

## What works from an upload

- **Phase 1, Demand:** a Search Query Performance report (Brand Analytics) for the user's own brand or a related ASIN they already sell: which queries carry volume and where purchases concentrate. It only covers queries where their brand's products appeared, not the whole category; say so, and for a category they don't sell in yet, ask what other research they have.
- **Phase 2, the neighborhood and need-states:** from that demand data plus what the user tells you about the product, and review text they paste from their own or competitor listings.
- **Phases 3–4, the PDP and the campaign plan**, written as a plan the user builds in their consoles. For an existing product's ads, a Sponsored Products search term report shows which queries already convert (map headers by meaning; read the attribution window from the headers and never relabel it).
- **Phase 5, tracking:** repeat the same report exports over time and compare like for like (same report type, period length and marketplace).

## What needs the Marketplace Ad Pros connection

Category recommendations and refinements, competitive analysis of the substitute set, review topics and trends, Share of Voice tracking, and every write (listings, images, campaigns, automation rules). Say so in one line where a step depends on one.

## Rules

- Map the headers by meaning and list the mapping in one line; one marketplace at a time; use code execution for every number.
- Query volumes in Search Query Performance are market totals, not the user's sales.
- Don't invent competitor ASINs, prices or review themes. Work from what the files and the user provide, and say where a tool would have filled a gap.
- Close with one line, once: connecting Marketplace Ad Pros (see the options at the top of `SKILL.md`) adds the competitive, category and review research and Share of Voice tracking.
